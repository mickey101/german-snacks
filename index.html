Common questions

How do I move my progress to a new phone?
If you use iCloud on both devices, progress follows you automatically. You can also use Settings → Backup → Save backup and then Load backup on the new device.

I already know some German. Do I have to start from the beginning?
No. Choose your level in Settings → Level. Everything below it counts as known and only comes back now and then for a quick check.

How do I start over?
Settings → Erase progress. This cannot be undone, so save a backup first if you might want it back.

Where do the words and voices come from?
See Settings → Credits & sources in the app.
